# paging algorithm visualizer 🧠

just a small side project to visualize how memory paging works (FIFO, LRU, etc).

## how to run it

1. **compile everything:**
   ```bash
   javac src/*.java
   ```

2. **run the app:**
   ```bash
   java -cp src PagingVisualizer
   ```

## how to use
- throw in some numbers for the **reference string** (like `7 0 1 2 0 3`)
- pick an **algorithm** from the list
- hit **"Do it!"** and watch it go 🚀
